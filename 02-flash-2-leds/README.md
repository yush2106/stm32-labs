## Flashing 2 LEDs alternatively

In the main.h file, define the Pin6 (GPIO_PIN_6) for LED1 and the Pin7 (GPIO_PIN_7) for LED2.

Set the pin status for these 2 LEDs alernatively, then each LED flashes for an interval time period.

## Process steps
Step 1: Trun on LED1.

Step 2: Trun off LED2.

Step 3: Delay.

Step 4: Trun off LED1.

Step 5: Trun on LED2.

Step 6: Delay.
