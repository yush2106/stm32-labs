# STM32 Labs
The STM32 microcontrollers are 32-bit which based on the Arm Cortex-M processor.

[STMicroelectronics](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html) develops and sells many types of development boards.

This respository is a learning note, try to ​practice projects for basic microcontroller functions.

## Development Board
In this respository use [STM32 NUCLEO-L476RG](https://www.st.com/en/microcontrollers-microprocessors/stm32l476rg.html) to test developed firmare.

## IDE (Integrated Development Environment)
We could development program and compile binary code in the IDE, [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html), then write the binary firmware into development board.
