## Generate random dice number and write to output data register

Use 7 LEDs for GPIO pins, PC0 to PC6.

When the onboard button is pressed, generate a random dice number.

Try to write hexadecimal value to output data register, and then turn on LED light for the dice number.

## Process steps
Step 1: Turn off all leds.

Step 2: Press the onboard button.

Step 3: Generate a random dice number.

Step 4: Write hexadecimal value to output data register and turn on leds for the random dice number.

Step 5: Delay.

Step 6: Turn off all leds.

Step 7: Press the onboard button, again.

Turn on LED for each dice number.
